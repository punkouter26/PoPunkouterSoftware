Sync button on the home page

2026-10-19 · / · local Development build, captured with Playwright at 390×844 and 1440×1000.

What moved

  • New "Sync" button in the action bar, beside the app count: right end of the bar on desktop, under the search box on phones.
  • It runs the same Azure rescan as "Rescan Azure" on /azure (POST /api/diag/refresh). While it runs, the label reads "Syncing…" and the button is disabled. The page reloads the cards when the scan finishes and shows a toast saying whether it worked.
  • It is only shown when the server will accept the rescan (/api/config → managementActionsEnabled). In Production that also needs a management key the browser does not have, so the button stays hidden there instead of failing on every click.
  • Nothing else on the page changed.
